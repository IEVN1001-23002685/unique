Imágenes de producto y variables

Usa únicamente recursos reales de public/prendas. Las imágenes locales se envían a Flask con POST /productos/<id>/imagenes; se verifican JPG, PNG o WebP de hasta 2 MB.

La biblioteca atiende productos, colores, materiales, bordados, categorías y la sección «Nuevas». La persistencia por API está disponible para producto/color; los demás destinos quedan señalados como pendientes de contrato.
