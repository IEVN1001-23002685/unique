Reglas de la captura

  • Las prendas se registran en unidades enteras; los materiales, en unidades base.
  • El SKU se elige del catálogo de M10: no se escribe manualmente.
  • Las llegadas de recepciones, calidad y devoluciones las generan sus módulos, no esta captura.
  • Un error se corrige con un reverso del Administrador; este registro no se modifica.

Al registrar se descuenta la existencia, se genera el movimiento MERMA y se evalúa la alerta MERMA_ALTA. El archivo de evidencia solo se referencia por nombre: este módulo no tiene endpoint de carga de archivos.
